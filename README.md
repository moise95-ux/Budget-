# Mon Budget

Petite application web de gestion mensuelle du budget.

## Fonctionnalités
- Navigation mois par mois
- Saisie/modification du salaire
- Ajout, modification et suppression des charges
- Saisie de l'épargne
- Calcul automatique du total des charges et du reste
- Diagramme circulaire dynamique
- Interface responsive mobile/desktop

## Lancer
Ouvrir `index.html` dans un navigateur.

## GitHub Pages
1. Créer un dépôt GitHub.
2. Déposer les fichiers `index.html`, `style.css` et `app.js`.
3. Dans Settings > Pages, sélectionner la branche principale et le dossier `/root`.
4. Enregistrer : GitHub Pages publiera l'application.

Note : cette première version stocke les données uniquement en mémoire pendant la session. Une prochaine version pourra ajouter une vraie sauvegarde locale, des graphiques historiques et une authentification/base de données.

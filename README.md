# Mon Budget
Application web mobile de gestion de budget mensuel.

- Accueil : salaire, charges, épargne, reste/découvert et diagramme circulaire.
- Salaire annuel : uniquement l'évolution du salaire sur 12 mois.
- Langues : Français 🇫🇷, English 🇬🇧, العربية 🇸🇦.
- Données conservées dans localStorage.
- Navigation et formulaires fonctionnels sur mobile.

# Mon Budget

Application de budget mensuel basée sur le salaire. Elle fonctionne dans le navigateur, sans serveur ni dépendance.

## Fonctions
- Navigation mois par mois, salaire et épargne modifiables
- Charges par catégorie (ajout, modification, suppression), copie du mois précédent
- Répartition du salaire en graphique en anneau, avec le reste ou le découvert
- Vue « Salaire annuel » : courbe sur 12 mois, un point touché modifie le salaire du mois
- Français, anglais, arabe (avec affichage de droite à gauche)
- Données enregistrées localement dans le navigateur (localStorage)

## Lancer
Ouvrez `index.html` dans un navigateur.

## Publier sur GitHub Pages
1. Poussez ces fichiers dans un dépôt GitHub.
2. Settings → Pages → Deploy from a branch → `main` / `(root)`.
